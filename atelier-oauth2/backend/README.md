# Backend Spring Boot

Prérequis : Java 21. Lancer Keycloak depuis la racine du projet avant le backend.

Depuis ce dossier, sous Windows PowerShell :
```powershell
mvn spring-boot:run
```
ou, si Maven Wrapper est disponible :
```powershell
.\mvnw.cmd spring-boot:run
```

API : http://localhost:8081
